# Your Journal List v0.1.5

把学校或学院的期刊目录带进 Zotero：导入 JSON / CSV，在文献列表查看等级，并按等级、匹配状态或关键词筛选当前列表。

- 同一安装包提供中英文界面，跟随 Zotero 语言；其他语言回退到英文。
- 支持期刊别名、大小写及 & 写法、ISSN、开头 The 变体；冲突显示待确认。
- 多份目录可切换、预览、替换、导出；升级保留本地目录。
- 原生下拉菜单和紧凑页签布局，支持明暗模式。

**安装：** 下载下方 `.xpi`，在 Zotero“工具 → 插件”中拖入安装。不要安装 Source code ZIP。

**兼容：** 声明兼容 Zotero 7–10 桌面版；已在 Windows / Zotero 10.0.6 验证中英文环境。其他版本及 macOS/Linux 尚未真机验证。

**数据：** 目录和等级由用户提供，AI 输出需要核对官方原件。目录保存在本机，不随 Zotero 同步。插件不调用 AI，不自动抓取学校政策或新论文。

---

Import institutional journal catalogs into Zotero, show grades beside papers, and filter the current list by grade, match status or keywords.

- English and Chinese UI in one package, following Zotero’s language (English fallback).
- Confirmed aliases, ISSNs and common title variants; conflicting evidence requires review.
- Multiple local catalogs with import preview, replacement and export; upgrades preserve data.
- Native dropdowns, compact tabs and light/dark appearance.

**Install:** Download the `.xpi` asset and drag it into Zotero’s Tools → Plugins window. Source code ZIP is not an installable plugin.

**Compatibility:** Declared for Zotero 7–10 desktop. Tested in both languages on Windows / Zotero 10.0.6. Other versions and macOS/Linux have not been tested on devices.

**Data:** Verify AI-prepared files against official policy documents. Catalogs remain local and do not sync through Zotero. No AI calls or automatic school-policy/new-paper fetching.
